Wo bekomme ich einen API-Key?
  1. 1
    console.anthropic.com aufrufen und Account erstellen oder einloggen
  2. 2
    Im Menü auf API Keys klicken, dann + Create Key
  3. 3
    Einen beliebigen Namen vergeben (z.B. FilaColor), Key erstellen
  4. 4
    Den angezeigten Key sofort kopieren — er wird danach nicht mehr vollständig angezeigt
  5. 5
    Key hier oben einfügen und speichern
Kosten: Die API ist kostenpflichtig, aber sehr günstig. Eine Farbanalyse kostet ca. 0,002–0,005 € (ein Bild + Antwort ≈ ~1.500 Tokens mit Claude Sonnet). Anthropic gibt neuen Accounts meist ein kostenloses Startguthaben.
